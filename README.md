# Base Detective

Обучающая SQL-игра: детективные дела, которые решаются запросами к базе данных.

## Стек

Vite + React + TypeScript + Tailwind, SQL-движок на sql.js в Web Worker.

## Запуск

```bash
npm install
npm run dev
```
